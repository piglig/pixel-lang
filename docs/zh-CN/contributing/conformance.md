# 一致性验证范围

[中文](conformance.md) · [English](../../en/contributing/conformance.md) · [文档首页](../README.md)

使用[分层门禁](verification.md)匹配修改范围。普通 unittest discover 不替代自举、生成编译器、图片、安装或真实编辑器验证。

| 约束 | 验证方向 |
| --- | --- |
| 颜色与空间可执行语义 | 改色、操作数位置、缩进、next/child、非法透明度和断开区域 |
| 无 OCR 与隐藏执行文本 | 真实无文本 PNG，移除附加元数据，图片独立运行 |
| AST 与规范化 | 区域/来源可检查，规范化语义保持及幂等 |
| IR 与 VM | 确定性字节码、优化开关一致、随机算术、调用/递归/循环、非法执行文件 |
| 类型与数据 | 数值边界、泛型、闭包、别名、枚举、错误、JSON、模块可见性与循环 |
| 自举与恢复 | 同源码多代完整产物相等，生成编译器及恢复编译器运行多文件真实项目 |
| 调试与效果 | 来源映射、快照、GC、逐状态回放、取消、文件权限和不重复写入 |
| 缓存与服务 | 开关差分、失效、重定位、失败不发布、期限、重启、过期结果 |
| 分发与工具 | 隔离 wheel、无源码图片、Node Bridge、DAP 和真实 VS Code 交互 |

任意维点结构只说明扩展边界，不证明支持三维源码。测试存在不代表当前产物已经通过；需运行并核对源码/产物身份。
