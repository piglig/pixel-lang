# 空间模型实现

[简体中文](spatial-model.md) · [English](../../en/internals/spatial-model.md) · [文档首页](../README.md)

空间类型属于语言和运行时，不以渲染器的 JSON 或图布局代替程序语义。公开操作契约见[空间参考](../reference/language/spatial.md)。

## 类型与身份

`frame` 声明名义坐标系，单位参与语义。Point3、Vec3 和 Transform3 保留坐标系类型，编译器拒绝隐式混用。
Space 保存坐标系、实体负载和连接负载类型。实体、连接身份稳定，不以显示名称或坐标相等代替身份。

`EntityId[F,T]` 和 `LinkId[F,T,L]` 保存所属空间和稳定业务键，与快照版本无关。实体值和连接值保存取得时的数据。操作接受类型化标识，不将数据快照隐式当作引用。分支中相同业务键表示同一逻辑对象；删除后复用键明确表示重建，查询缺失返回 Option。外来空间标识被拒绝。

## 快照与更新

空间操作返回新快照，保留旧值和类型化负载。并行边与自环合法，查询顺序由插入顺序决定。
移动实体保留连接，删除实体前须断开关联边，或明确选择 removeCascade。运行时验证位置、预算和身份后才发布结果，失败不部分修改输入。

flow 将空间快照作为普通状态保存。执行故障回滚步骤；业务 Result.Err 的处理由转移函数明确决定。
检查点保留空间身份注册表和资源计数，恢复后继续执行仍遵守相同边界。

## 查询与变换

半径邻域、方向投影和显式连接是不同关系。优化后的空间索引必须与直接查询得到相同结果，
包括边界、排序和非法输入行为。位置受平移影响，方向不受平移影响；单位转换和变换组合显式完成。
不承诺不同浮点实现跨硬件逐位一致。

## 源码与 Studio

编译器保留坐标表达式的 Unicode 标量范围，宿主转换为 UTF-16 编辑范围。来源不参与值相等或哈希。
直接字面量支持坐标修改，计算得到的位置只导航到表达式；不根据坐标相等猜测来源。

相机、缩放和分页只影响展示。源码编辑影响表达式的所有执行实例，运行事件只更新运行状态。
过期快照不允许写回。真实拖动与键盘撤销需要独立交互验证，见[Studio](../guides/studio.md)。

## 交付与验证

PNG 保存可恢复的类型、坐标、连接和表达式；三维模型文件不替代程序载体。
恢复后修改 Z 或连接负载应能改变程序结果，而相机变化不应改变结果。

验证覆盖多坐标系拒绝、单位换算、历史快照隔离、预算恢复、PNG 往返和安装后的编辑器。
执行入口见[分层验证](../contributing/verification.md)。
