# 中间表示 IR（0.8）

[中文](ir.md) · [English](../../en/internals/ir.md) · [文档首页](../README.md)

与物理表示无关的栈式 IR 包含 version、records、enums、entry 和 functions。
入口唯一、无参数、返回 unit，没有模块初始化器。函数保存参数类型、捕获单元类型、局部槽、结果及指令。
指令含 op、可选 arg 和来源信息。CONST/LABEL 为符号，汇编驻留类型化常量、解析标签并生成字节码。
函数/模块由数字 ID 标识，局部用固定槽；降低和执行不需要 RGBA 操作。优化移除跳到下一标签的跳转。

参数从左到右求值；短路使用 DUP、条件跳转、POP。集合遍历先取快照，临时槽保存索引/键/值，
continue 跳到推进块。break/continue 仅对离开的处理器发出 END_TRY。
JSON_DECODE 携带已解析目标模式，不完整编辑 AST 不能生成可执行产物。
重复泛型参数元组共享具体实例，匿名函数降低为独立受检查体。
CAPTURE/CLOSURE 保留绑定身份，BIND 创建新声明，INVOKE 带完整签名，枚举使用类型化 ENUM 操作。

## 函数复用

ir_cache.pxl 匹配规范模块路径、声明身份、具体实参和闭包位置，同时验证精确源码与传递依赖接口戳。
当前程序仍执行所有语义检查和帧规划。
当前规划决定执行 ID；缓存函数引用、名义类型和指令模块 ID 会重定位，只有源码未变才保留位置。
常量到新汇编阶段才编号，字符串载荷不作为标识符处理；模式和入口从当前规划重建。

函数载荷按需加载并独立遵守 JSON 限制。未变载荷用独立旧文件名保留，变化者重新序列化。
无缓存、非规范路径或函数过大均可正常降低。服务只发布完整成功快照，详见[协议](../reference/compiler-service.md)。
