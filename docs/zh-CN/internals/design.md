# 设计原则与后续方向

[简体中文](design.md) · [English](../../en/internals/design.md) · [文档首页](../README.md)

本页记录设计取舍和明确未承诺的后续方向。语言参考定义当前行为，验证报告证明某个具体快照。

## 已采用的设计原则

- **一种普通值模型。** 记录、数组、映射和枚举按值传递；`let` 只读，`var` 可修改本地值。
  写回调用者必须显式使用 `inout` 和调用参数 `&`。实体、连接与活跃流程实例具有明确身份。
  规则见[数据语义](../reference/language/data.md)和[函数](../reference/language/functions.md)。
- **一种函数模型。** 普通计算使用 `fn`，外部效果显式标注 `effect`；闭包按值捕获。
  `inout` 的写回权限与外部效果分别检查，不能把无 `effect` 等同于可缓存的纯调用。
- **明确的状态推进。** flow 区分构造与 `step`，读取旧状态、计算 `next`、成功后原子提交。
  调度属于宿主或库；XYZ 不隐含时间。见[事件应用](../guides/state-machines.md)。
- **空间属于程序语义。** 坐标系、位置、方向、稳定实体身份与类型化连接参与计算；
  Studio 投影和编辑同一份权威源码，不维护第二份可执行图。见[原生空间](../guides/spatial-programming.md)。
- **失败显式表达。** 缺失使用 Option，可恢复失败使用 Result，`?` 传播；
  取消、预算和程序故障终止执行。见[错误处理](../reference/language/errors.md)。
- **每项操作一个公开入口。** 容器基本操作使用接收者方法，通用算法集中在标准库。
  集合键服从统一的 Hashable 契约，不人为限制为字符串。见[集合](../reference/language/collections.md)。
- **文本与像素表达同一程序。** PNG 保存显式语义区域，恢复不依赖隐藏源码。
  见[编码](../reference/formats/encoding.md)。

## 实现边界

原生常驻编译器拥有绑定、声明类型、函数语义、帧规划和 IR 查询缓存；失效由语义依赖决定。
全局声明索引、类型约束验证和特化仍有全项目阶段，不能把函数查询复用称为全阶段增量化。
具体契约见[编译服务](../reference/compiler-service.md)。

旧 Python 编译与编辑前端已删除。Python 仍承担运行、调试回放、服务与独立参考验证，
具体职责见[Python 边界](python.md)。参考实现不充当原生编译失败时的兼容回退。

## 后续评估，尚非语言承诺

1. 评估值块的控制流限制能否与普通块统一；先明确作用域和退出清理，不添加第二套块语法。
2. 改善泛型推导和诊断，减少显式类型实参；保持解析不依赖名称预扫描。
3. 继续增量化全局分析与编辑索引，以修改后的实际延迟和失效范围验收。

## 验证与文档职责

语言参考描述规则，指南描述使用流程，本页解释取舍。[分层验证](../contributing/verification.md)
定义检查入口与发布要求。单次测试数量、耗时及安装状态保存在绑定输入指纹的报告中，
不散布在语法章节，也不代表后续修改已通过。编译器种子身份由随附 manifest 标识。

测试按行为和交付边界组织：同一边界的重复夹具共享，原生／参考 VM 差分、增量／全量等价、
自举固定点、PNG 恢复和安装后的 Studio 检查分别保留。
