## 计算与依赖

普通函数默认禁止隐式外部效果。局部 `var` 修改自己的值；参数写回必须声明 `inout`。
旧的 `mut`、`Frozen`、`freeze` 与 `thaw` 不属于新代码的数据模型。

```pixellang
fn Double(values: [int]) -> [int] {
    var result: [int] = []
    for value in values { result.append(value * 2) }
    return result
}
```

flow 直接书写表达式，由原生编译器构建依赖图；旧 `node`／`connect` 接线语法已删除。
下面的声明将创建参数与每步输入分开，`Counter(0)` 创建实例，`counter.step(2)` 推进一步。
即使没有状态，flow 调用也始终创建实例；普通直接计算使用 `fn`。

```pixellang
flow Counter(initial: int) step(delta: int) -> int {
    state value = initial
    let updated = value + delta
    next value = updated
    output updated
}
```

表达式 flow 的名称在每步作用域内预声明，允许命名结果前向引用；编译器按依赖排序，
没有依赖约束的就绪计算按源码顺序选择。依赖边保存声明、使用位置和消费表达式的 AST 身份，
同名的 lambda 参数或模式绑定不会被误认作外层图节点。闭包捕获和记录字段简写也参与依赖分析。
创建参数是只读配置，可用于初始化和每步计算；state 与 instance 的初值不能读取每步输入、其他状态或计算结果。
每步计算读取旧状态，因此 next 对状态的写回不形成同一步组合依赖环。
这些规则由原生解析、绑定、类型检查与执行后端共同保证。

纯调用不创建持久实例。有状态子流程须显式声明稳定身份，不能由表达式排序、
公共子表达式合并或执行次数决定。AST 与 IR 保留依赖、状态、实例和提交边界；
编译器不得通过生成临时源码或重新解析 JSON 图来代替这些原生结构。

## 持久子实例

```pixellang
flow Parent(initial: int) step(delta: int) -> int {
    instance counter = Counter(initial)
    let result = counter.step(delta)
    output result
}
```

instance 的构造目标必须是可见的 flow 声明。创建父实例时构造子实例；普通函数调用不创建实例。
子实例身份由声明决定，与表达式重排无关。子实例不能赋给其他变量、作为普通参数传递或从闭包中推进。
每次父流程推进，同一子实例在一条执行路径上最多推进一次；需要复用结果时绑定为 let。
互斥 match 分支可以分别推进同一个子实例，未选中的分支不执行；没有推进的子实例保留原状态。

子流程与父流程共用一次提交边界：next 的右侧读取各自的旧状态，父流程成功后整体提交。
任意执行故障不得留下已提交的子状态。创建、每步计算与提交必须在 IR 中保持独立，
不能用普通函数调用加隐藏的全局句柄模拟这一契约。类型、推进次数与故障回滚由原生检查和执行保证。

## 状态、事件与提交

状态属于显式创建的运行实例。复制句柄仍指向同一实例；创建新实例才会得到独立状态。
每一步读取旧状态快照，计算 `next` 候选与 `output`，全部成功后统一提交。
嵌套子实例与父实例原子提交；执行故障不允许部分状态或部分历史提交。

业务 `Err` 是正常返回值，不隐式回滚用户明确选择的下一状态。状态转移必须明确处理
不接受的事件。普通数据使用值语义，更新后的状态不能改写输入、先前输出或历史快照。

原生契约允许每个状态单元至多一个 `next`；未声明更新时保留旧值，不生成隐式指令或图边。
状态初值可使用创建参数或允许的常量表达式，不能读取每步输入或任意执行外部 I/O。
反馈通过状态单元跨越逻辑步，不允许无状态依赖环。

事件驱动以显式输入为基础，逻辑时钟是可选输入。固定步长属于驱动策略，
不属于 flow 类型的必要条件。宿主通过应用配置选择根实例并调度事件；
程序通过 `instance.step(...)` 显式推进，见[状态机指南](../guides/state-machines.md)。
XYZ 保持空间含义；历史视图可以沿某个显示轴排列时间，但不会改变程序坐标的含义。

## 效果与调试

I/O、隐式时间和隐式随机数不能隐藏在纯计算中；外部操作使用 `effect fn`。
回调与跨模块调用同样检查效果权限。空间状态创建只获得受限的实例构造权限，
不能由此获得文件访问或其他外部权限。

独立节点的计算、错误选择与追踪必须具有确定性。后续并行执行也须保留该契约。
调试器显示输入来源、该步输出及状态前后值；回放不重复外部写入。

Studio 使用同一程序语义进行源码与图编辑，不维护第二份权威连接 JSON。
编辑视图中的布局、相机和缩放不改变计算结果。原生图编辑可修改输出、状态和子实例创建参数；真实拖动与键盘撤销使用独立桌面交互验收，不能用服务测试替代。

## PNG 交付

当前原生流程可编码为语义像素、恢复源码并重新编译。命名计算、状态和输入具有
明确身份，跨模块目标与记录字段投影不依赖可选的名称元数据。非法区域和不存在的引用
须在执行前拒绝；新语法也必须遵守同样的往返与诊断要求。

验证覆盖导入流程、嵌套实例、空间快照初值、调试映射及历史恢复；具体运行需绑定当前源码与产物。
