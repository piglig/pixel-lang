# 数值规则（语言 0.8）

[中文](numbers.md) · [English](../../../en/reference/language/numbers.md) · [文档首页](../../README.md)

int 是检查溢出的有符号 64 位整数。float64 是有限 IEEE 754 binary64，使用最近舍入、正好中间时取偶数。
允许渐进下溢和带符号零；NaN 与无穷不是语言值。算术溢出不可捕获；外部数字非法或显式转换越界是可捕获数据错误。
整数和浮点的除零、取余零均可捕获。

浮点字面量必须含小数或指数，如 1.0、1e3、1_000.25、1.5e-2；小数点两侧必须有数字，分隔符只允许位于数字之间。
前置负号是一元取负。字面量、像素、常量池、运算、JSON 和回放均保留负零。
即使预期 float64，字面量 1 仍是 int。

+ - * / % 和比较要求相同操作数类型，一元取负接受两种数值类型。整数除法向零截断，浮点除法舍入到 binary64。
余数与被除数同号且绝对值小于除数；浮点余数采用 fmod 语义。+0.0 与 -0.0 相等，没有隐式近似相等。
++/-- 加减整数一，只适用于 int；浮点更新写作 += 1.0 或 -= 1.0。

`float64(int)` 舍入到最近 binary64，超过 2^53 的整数可能不能精确表示。
`int(float64)` 向零截断，截断结果超出 [-2^63, 2^63) 时失败。同类型数值转换保持值。
不允许 bool/string 强制转换。`parseFloat64(string)` 接受带可选符号、小数和指数的十进制字符串，
不接受空白或分隔符，并拒绝非有限结果。

`string(float64)` 输出可往返同一 binary64 的最短十进制表示，保留浮点形式（.0 或指数）及负零。
JSON 转 float64 舍入并拒绝非有限值；转 int 对原始 JSON 十进制数执行精确整数检查。
jsonFrom 与 jsonStringify 保留浮点可往返表示。

物理编码使用 R=20、保留载荷为零的头，后跟四个 16 位数据字，承载大端 IEEE 754 位。
非法保留载荷和非有限位模式被拒绝，验证不依赖名称元数据。
