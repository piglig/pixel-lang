# PixelLang 是什么？

[简体中文](product.md) · [English](../en/product.md) · [文档首页](README.md)

PixelLang 让你编写程序、观察它如何运行，再把它作为一张图片分享出去。它是一门空间编程语言：位置和连接本身，也可以参与计算。

## 从熟悉的问题开始

你可以用 PixelLang 读取数据、排序记录，把一个程序拆成多个文件。也可以描述空间里的事物：附近的对象、地点之间的路线，或电梯经过的楼层。

对于需要响应事件的程序，`flow` 会记住每一步的状态。订单可以记住是否已经付款，控制器也可以根据当前状态和新的输入，决定下一步做什么。

可以看看[订单示例](../../examples/native-orders/README.md)、[空间电梯](../../examples/native-elevator/README.md)或[数据报告](../../examples/ledger/README.md)，了解这些能力如何用在实际程序里。

## 把程序分享成 PNG

写好并测试代码后，你可以把它导出为 PNG。安装了 PixelLang 的人可以给这张图片提供新的输入并运行，也可以恢复代码，接着修改。

程序结构保存在像素中，所以分享时需要保留原始图片，不要缩放或编辑。恢复后的程序行为一致，但不会保留原有注释和排版。程序需要的数据，以及读取文件的权限，在运行时另外提供。

你也可以一直使用文本文件开发。导出图片是一种分享方式，不是每次运行程序都必须经过的步骤。

## 探索空间和状态

X、Y、Z 描述事物的位置。移动一个实体，查找附近实体的结果就可能改变。实体之间的连接也可以带上数据，比如一条路线的成本。

时间与位置分开表达。每次给 `flow` 一个输入，它就读取上一步的状态，再一起提交本步的更新。在 Studio 中，你可以检查变量，也可以回看记录下来的步骤。旋转相机或整理图形布局，只会改变观察方式。

[三维空间指南](guides/spatial-programming.md)和[状态机指南](guides/state-machines.md)会带你运行具体的例子。

## 适合现在用在我的项目里吗？

PixelLang 目前处于开发预览阶段。语法和文件格式仍在完善，欢迎尝试并反馈使用感受。

工具链目前支持 macOS 和 Linux，需要 Python 3.11+ 和匹配平台的原生编译器包；[安装指南](guides/installation.md)会介绍如何准备。目前使用本地依赖，尚未提供网络包注册表或语言级网络 API。

编译器本身用 PixelLang 编写。CLI 和 Studio 使用它的原生可执行文件，普通程序则在 PixelVM 中运行和调试。如果你想参与底层实现，可以从[架构指南](internals/architecture.md)开始。
