# PixelLang 产品说明

[中文](product.md) · [English](../en/product.md) · [文档首页](README.md)

PixelLang 是以颜色和空间关系表达程序语义的静态类型语言。开发者可用自有文本语法编写算法和数据处理项目，
通过语义像素 PNG 交付程序，并在 VS Code Studio 中开发、调试和观察执行过程。

## 使用对象与核心流程

主要面向语言实现研究、可视化编程，以及字符串、数组、排序、统计和多文件数据处理。
典型流程为：编写 .pxl → 检查/测试 → 导出包含可达模块的 PNG → 提供独立输入执行 → 恢复可编辑源码。
图片恢复保持程序含义和名称，不恢复原始注释与排版。

## 产品约束

- 颜色表示 token 类别与载荷，不直接等于 VM 指令；坐标、顺序、区域与连接参与语义。
- 图片包含真正可解码的像素程序，不使用 OCR，不把完整源码、AST 或字节码藏在图片元数据里执行。
- 编码、空间 AST、语义检查、IR 与 VM 分层；文本可以直接编译，无需图片往返。
- 源码、可执行产物、运行状态、时间记录彼此独立。回放不修改源码、不重复外部文件写入。
- 构建使用显式依赖、版本化格式和确定性处理；相同环境/输入/选项下可以比较完整产物。
- 编译器由 PixelLang 实现；Python 仍承载 VM、服务、部分编辑工具及引导参考实现。

## 当前能力

语言提供 int64、有限 float64、Unicode 字符串、数组、字符串键映射、名义记录、泛型、枚举、Option、match、
函数值、闭包、结构化错误和类型化 JSON。模块支持显式导出与本地依赖锁。
标准库覆盖集合回调、排序、CSV、文本、统计、JSON 和授权文件 I/O。
运行时检查边界、类型、溢出和预算，支持调用、递归、GC、调试及确定性回放。

Studio 基于 VS Code，提供语言导航、诊断、格式化、构建/测试、PNG 导出/恢复、断点、变量和逆向单步。
二维编辑支持受检查的字面量/操作符替换和相邻语句移动。时间视图的 Z 为执行转移，源码本身仍是二维。
编译服务支持取消、期限、版本快照守卫、解析/IR/完整产物缓存。

## 当前边界

不兼容 Go/Java 语法或生态；不支持完整三维源码、网络 I/O、网络包注册表、独立原生机器码或 WASM 后端。
运行工具仍需要 Python，Cython VM 仅为可选实验。
PNG 必须保持精确像素，不可缩放、有损压缩或色彩变换。
文件权限显式授予，回放使用记录效果；宿主正在执行的调用不保证可被立即中断。

## 质量要求

语言与像素路径应给出一致行为，诊断具有来源；格式和缓存不能绕过类型、资源、取消或依赖检查。
自举通过同源码多代完整产物比较及生成编译器回归验证，PNG 交付通过完整恢复后编译新程序验证。
测试、性能和安装验收分别运行，不以计划或旧结果代替当前验证。
