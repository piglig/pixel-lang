# Contributing

[简体中文](CONTRIBUTING.zh-CN.md) · [English](CONTRIBUTING.md)

Thank you for improving PixelLang. The full workflow is in the [contributor guide](docs/en/contributing/README.md).

- [Prepare your environment](docs/en/guides/installation.md)
- [Choose verification scope](docs/en/contributing/verification.md)
- [Report performance issues](docs/en/contributing/performance.md)

Include reproducible input, expected behavior, actual results and verification commands in issues and PRs. Update both documentation languages for semantic changes; development does not preserve legacy compatibility entry points.
