# PixelLang Studio

[中文](README.md) · [English](README.en.md)

VS Code 中的 PixelLang 开发与调试工作站。需要 Python 3.11+ 和 Pillow，扩展自带编译器。

[安装、使用与调试指南](../docs/zh-CN/guides/studio.md) · [项目指南](../docs/zh-CN/guides/projects.md)

在仓库根执行 `npm --prefix vscode ci`、`npm --prefix vscode run package`，通过 Install from VSIX 安装生成扩展。
打开 .pxl，执行 PixelLang: Open Studio 或按 F5。打包不会发布扩展。
