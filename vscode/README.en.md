# PixelLang Studio

[中文](README.md) · [English](README.en.md)

The PixelLang development and debugging workstation in VS Code. Requires Python 3.11+ and Pillow; the compiler is bundled.

[Installation, usage and debugging](../docs/en/guides/studio.md) · [Projects](../docs/en/guides/projects.md)

From the repository root run `npm --prefix vscode ci` and `npm --prefix vscode run package`, then install the generated extension with Install from VSIX.
Open .pxl, run PixelLang: Open Studio or press F5. Packaging does not publish the extension.
